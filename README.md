# trilha-javascript

Exercícios da trilha de JavaScript da DIO (Digital Innovation One): variáveis e operadores.

## Conteúdo

- `aula.js` - exemplo de variável e `console.log`.
- `primeiro-desafio.js` - calcula o custo de uma viagem a partir do preço do combustível, consumo (km/l) e distância.

## Tecnologias

JavaScript puro.

## Como rodar localmente

Com Node.js instalado:

```bash
node aula.js
node primeiro-desafio.js
```
